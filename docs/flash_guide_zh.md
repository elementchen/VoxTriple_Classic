# 🚀 VoxTriple Classic 固件烧录与极速升级新手教程（傻瓜式）

本教程专为**不懂代码、不懂开发、不熟悉命令行、未安装 Python 及 ESP-IDF 环境**的普通用户设计。通过图文并茂的说明，手把手教您如何为一块全新购买的 ESP32 开发板进行首次固件烧录，以及后续如何使用桌面 App 进行一键有线升级。

---

## 📂 第一部分：准备工作

在开始之前，请您先下载我们发布好的所有必备软件包：

1. **下载烧录工具（乐鑫官方 Flash 下载工具）**：
   * 访问乐鑫官网的工具下载页：[乐鑫官方工具下载](https://www.espressif.com.cn/zh-hans/support/download/other-tools)；
   * 找到并下载 **`Flash 下载工具 (ESP32 Flash Download Tool)`**；
   * 下载后将其解压到电脑的任意文件夹（如桌面）备用。
2. **下载固件与配置程序**：
   * 访问我们新版项目的 GitHub 发布页面：[VoxTriple Classic v1.0.10 Releases](https://github.com/elementchen/VoxTriple_Classic/releases/tag/v1.0.10)；
   * 在「Assets / 资源列表」中下载以下三个文件：
     1. **`esp32_bt_mic_merged_v1.0.10.bin`** —— **一键完整出厂镜像**（专门用于全新开发板的首次初始化烧录）。
     2. **`esp32_bt_mic_v1.0.10.bin`** —— **常规应用固件**（用于后续在桌面配置客户端中一键极速 OTA 升级）。
     3. **`VoxTripleConfig.exe`** —— **Windows 配置与升级客户端**（绿色免安装单文件版）。
3. **准备硬件**：
   * 一块 NodeMCU-32S (ESP32-WROOM-32) 开发板。
   * 一根支持数据传输的 Micro-USB 或者是 Type-C 串行线缆（注意：请不要使用只能充电的纯电源线，否则电脑会识别不到端口）。

## ⚡ 第二部分：全新开发板首次烧录（小白一键引导）

如果您的开发板是一块刚买来的新板子，或者之前烧录过别的不相干程序，请使用本节方法进行首次出厂烧录：

1. **接线并连接电脑**：
   * 用 USB 数据线将 ESP32 开发板插到 Windows 电脑的 USB 接口上。
2. **运行乐鑫烧录工具**：
   * 打开第一步中解压好的文件夹，双击运行 **`flash_download_tool_x.x.x.exe`**。
   * 在弹出的选择框中，分别选择以下选项：
     * **Chip Type / 芯片类型**：选择 **`ESP32`**
     * **Work Mode / 工作模式**：选择 **`develop`**
     * 点击 **`OK`** 进入主烧录界面。
3. **配置一键合并固件（极其重要）**：
   * 勾选第一行最左侧的复选框，使其亮起；
   * 点击第一行右侧的 **`...`** 按钮，在弹出的文件浏览器中选择您刚才下载的 **`esp32_bt_mic_merged_v1.0.10.bin`**；
   * 在它右侧的 **`@`** 符号后面的输入框中，输入数值：**`0x0`**（这就是唯一的烧录偏置地址，其余三行全部留空！）。
4. **底层配置项检查（保持默认即可）**：
   * **SPI SPEED**：`40MHz`
   * **SPI MODE**：`DIO`
   * **FLASH SIZE**：`32Mbit` (即 4MB，这是最通用的出厂配置)
5. **选择电脑串口**：
   * 在主界面最下方的 **`COM`** 下拉框中，选择您开发板对应的串口（如 `COM5`，如果您分不清是哪一个，可以拔掉 USB 再插上，看下拉框中哪个 COM 号消失了又出现，那就是它）；
   * 在 **`BAUD`（波特率）** 下拉框中，选择 **`115200`**（为了彻底隔绝阻抗噪声和电路抖动，建议新手在此波特率下烧录，非常稳健）。
6. **开始一键烧录**：
   * 确认前面的复选框已勾选，地址填的是 `0x0`，点击左下角的 **`START`** 按钮；
   * **💡 贴心小提示**：对于有些开发板，如果点击 `START` 后一直显示 `等待上电同步 / Waiting for sync`，请用手指**长按开发板上的 IO0 按键（通常标有 BOOT 字样）** 1-2秒，即可瞬间触发自动烧录；
   * 当界面上出现绿色的 **`FINISH`（完成）** 字样时，说明您的开发板已经完成了出厂初始化，您的四键蓝牙键盘麦克风系统已经正式跑起来了！

## 🔄 第三部分：日常一键智能升级固件（全新全自动流程）

一旦您的开发板通过第二步运行了我们的固件，今后如果官方发布了新版本（例如云端推出了新版 `1.0.11`，而您的板子上运行的是 `1.0.10`），您**完全不需要**再次使用复杂的 Flash 工具或长按 Boot 键。只需直接使用我们的配置 App，即可享受全自动检测、自动下载和 20 秒极速 OTA 有线升级：

### 智能升级步骤（首选）：
1. **连接您的开发板**：
   * 运行 **`VoxTripleConfig.exe`**；
   * 在最上方的串口下拉框选择开发板串口并点击「Connect / 连接」。
2. **全自动在线版本检测**：
   * 连上后，App 会自动从开发板读取当前版本号，并与 GitHub 官方发布的最新的版本号进行比对：
     * **若已经是最新版**：在顶部固件版本号旁边会静默亮起绿字 `(已经是最新版固件)`。
     * **若有更新版本**：在顶部版本号旁会**醒目浮现出一个「Update / 升级固件」按钮**，并用小字写上最新版本（如 `(最新版: 1.0.11)`）。
3. **一键 Cloud Update 闪电升级**：
   * 您只需直接点击顶部的那个**「Update / 升级固件」**按钮；
   * 软件会**全自动切换**到固件升级选项卡（Tab 2），并开启自动升级流程：
     * **自动下载**：App 会在后台自动从 GitHub 极速下载最新版的应用固件，并在进度条上实时展示下载百分比；
     * **自动写入**：下载完成的一瞬间，进度条归零，并开始展示 20 秒有线直写 OTA 进度。
     * **软重启**：写入完毕后，软件提示“升级成功”，开发板会自动软重启并跑在最新固件上。配置 App 会自动安全断开，此时您只需重新连接串口即可！

### 💾 网络不好？使用离线缓存升级：
如果您的电脑网络不佳，在点击升级按钮后反复下载失败，您可以通过以下方式“手动离线升级”：
1. **新建 `cache` 缓存文件夹**：
   * 在您配置 App（`VoxTripleConfig.exe`）所在的同级目录下，新建一个名字叫 **`cache`** 的文件夹；
2. **手动下载固件并放入**：
   * 用其它方式（如手机或浏览器）从 GitHub 下载最新发布的应用固件 `.bin`（例如 [esp32_bt_mic_v1.0.10.bin](https://github.com/elementchen/VoxTriple_Classic/releases/download/v1.0.10/esp32_bt_mic_v1.0.10.bin)）；
   * 将该二进制文件放入您刚才建立的 `cache` 目录下，并重命名为对应版本格式（如 **`cache/esp32_bt_mic_v1.0.10.bin`**）；
3. **点击升级**：
   * 连上串口后点击「Update / 升级固件」按钮。App 在检测本地缓存时会发现该文件已经存在，将**直接跳过网络下载阶段**，瞬间开启 20 秒极速有线 OTA 写入！

## 🔑 第四部分：常见问题与排查指南

* **Q：为什么我的电脑插上 USB 线后，烧录工具和配置 App 的下拉框里找不到 COM 串口？**
  * **A**：有两种可能：① 您使用的是纯充电的电源线，请更换能传输数据的 Micro-USB / Type-C 数据线；② 您的电脑缺少串口芯片驱动（开发板常用 CH340 或 CP2102 芯片），请在网上搜索下载并安装对应的 Windows CH340 驱动程序，即可在设备管理器中显示出端口。
* **Q：为什么物理按键在 App 里可以监测到按下，但电脑却没有打字响应？**
  * **A**：配置 App 是配置通道。在配置结束后，您必须让开发板与电脑建立**经典蓝牙（Classic Bluetooth）**配对！请打开 Windows 设置 ➡️ 添加蓝牙设备 ➡️ 搜索并配对 `VoxTriple_Classic`。配对成功后，蓝牙键盘和音频输入设备就会由系统自动装载就绪，您就可以正常使用了！
